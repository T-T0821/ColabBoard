              キーボード操作

              Tab / Shift+Tab
              要素を読む順(上から下、左から右)に選ぶ
              Alt+矢印
              その方向で一番近い要素へ移る
              矢印
              選んだ要素を動かす(Shift で 10 倍)。選んでいなければ画面を動かす
              Alt+Shift+矢印
              その方向の要素とコネクタでつなぐ(なければ新しく置いてつなぐ)
              S R O T F → Enter
              付箋・四角形・楕円・テキスト・フレームを画面の中央に置く
              Enter / F2
              選んだ要素の文字を入力(Esc で確定)
              Delete
              選んだ要素を消す
              Ctrl+Z / Ctrl+Shift+Z
              元に戻す / やり直す
              Ctrl+D / Ctrl+G
              複製 / グループ化
              + - 0 1
              拡大・縮小・100%・全体を表示
              Ctrl+F
              ボード内を検索
              Esc
              選択を解除

              マウス

              スクロール / Space+ドラッグ
              画面を動かす
              Ctrl/⌘+スクロール
              拡大・縮小
              Shift+クリック
              選択に追加する
              Shift+角をドラッグ
              縦横比を保ったまま大きさを変える
              ダブルクリック
              文字を入力

              画面読み上げを使っているときは、見出し「ボードの要素」の一覧から要素を選ぶこともできます。
